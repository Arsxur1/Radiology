# Validation report (TZ §15, §16)

> **Не клиническая валидация.** Все числа получены на синтетическом генераторе
> и небольших **сабсетах** открытых датасетов. Это инженерная валидация
> пайплайна (детекция находок + точность измерений), а не клиническое
> исследование. CardioLens — инструмент поддержки решений, не медицинское
> изделие (§0, §10).

Как воспроизвести (адаптеры читают **локальный** чекаут; сеть к PhysioNet в
рантайме не нужна):

```bash
python -m cardiolens.validate                          # синтетика (offline)
python -m cardiolens.validate --ptbxl <root>           # PTB-XL
python -m cardiolens.validate --ecg-arrhythmia <root>  # Chapman/Ningbo
python -m cardiolens.validate --ludb <root>            # точность делинеации
```

## Методология

- **Источник-агностичный харнесс** (`cardiolens.validation`): размеченный случай
  = сигнал + gold-находки (+ gold-интервалы), прогоняется весь пайплайн, считаются
  per-class sensitivity/specificity и, где есть gold, MAE интервалов (§16).
- **Скоринг по источнику.** Каждый датасет скорит ровно те коды находок, которые
  способна выдать его разметка (выводятся из карт `PTBXL_SCP_TO_CODE`,
  `SNOMED_TO_CODE`), — иначе таблица засоряется классами с нулевой опорой.
- **Сабсеты** сбалансированы по меткам (стратификация по SCP/SNOMED, до 80–90
  записей на класс для PTB-XL и до 50 для Chapman/Ningbo — прескрининг заголовков
  по `#Dx`). Сабсеты **обогащены патологией** — специфичность на них занижена
  относительно общей популяции (см. ограничения). Числа устойчивы: при росте
  опоры с ~30 до ~90/класс (PTB-XL) macro почти не изменилась (0.63→0.63).
- Ядро (Слои 1–5) работает офлайн; LLM-нарратив Слоя 6 в валидации не участвует
  (`StubProvider`).

Macro — по 10 классам с достаточной опорой. `rvh` (opora n=8) и `paced_rhythm`
(n=2) в этом сабсете почти не представлены и валидированы отдельно (RVH — D15e;
ЭКС — таргетно 60 PACE/60 SR, 0.83/0.95, D15g). ST-строки — после перевода на J+60
(D15j/D15k); харнесс-спецификация считается против **всех** негативов (не только
чистого SR), поэтому выше, чем в таргетных исследованиях (STE 0.80 vs 0.75).

**ST-элевация — J+60 + лид-специфичный порог (DECISIONS.md D15j):** правило
переведено с J-точки на J+60 (конвенция ST-амплитуды SCP-ECG — J-точка недомеряет
элевацию, sens 0.14→0.29), с порогом V2–V3 = 200µV (ранняя реполяризация) и
обязательной смежностью ≥2 отведений одной территории вместо любых двух. Строгое
улучшение по обеим осям: 0.14/0.64 → **0.29/0.75**, PPV 0.13→0.35. Абсолютная
чувствительность ограничена «рыхлой» меткой STE_ (28 записей, часть — элевации
100–200µV в V2–V3, которые гайдлайны справедливо не считают STEMI).

**ST-депрессия — замер в J+60 (DECISIONS.md D15k):** депрессия читалась в J-точке,
которая сидит в надире S / junctional-провале и завышала депрессию на норме (spec
0.48). Перевод на J+60 (стандарт замера ишемической депрессии) поднял спецификацию
до 0.70 (PPV 0.65) ценой чувствительности (~0.68→0.45): «потерянное» — в основном
доброкачественная восходящая junctional-депрессия, которая к J+60 разрешается.
Осознанный обмен в пользу специфичности для §8-находки (0.48 был почти бесполезен).

**RBBB и LBBB — обе стены сняты устойчивой шириной QRS (DECISIONS.md D15o).** Диагноз
(D15i/D15n): fiducial QRS-offset нестабилен в обе стороны — недомеряет широкие блокады
(RBBB: 48% CRBBB ≥120) и перемеряет норму (40% нормальных ЭКГ ≥120 → ложные LBBB).
Терминальный R+ в V1 надёжен (93%), морфо-гейт V6 не разделял (ложные — норма,
мис-измеренная широкой). Решение — энергетическая оценка ширины (сумма |производной|
по отведениям, непрерывный участок вокруг R, frac 0.05, калибрована на LUDB): NORM
1% ≥120, CRBBB 89%, CLBBB 100%. End-to-end: **RBBB 0.42/0.98 → 0.82/0.98**, **LBBB
0.62/0.61 → 0.97/0.93**. Остаток RBBB — амплитудно-малый терминальный R′; диагностич.
полоса — дальнейший v2.

**LVH — Cornell-вольтаж исследован, не принят (DECISIONS.md D15m):** добавление
Cornell (S_V3+R_aVL) как OR к Соколов-Лайон роняет спецификацию ниже 0.96 при любом
пороге (0.66/0.70 на гайдлайн-пороге); спец-сохраняющая точка не даёт прироста
чувствительности. Высокая спецификация — главная ценность LVH-детектора, разменивать
её не оправдано. Оставлен Соколов-Лайон-only (0.46/0.96).

## Известные ограничения

- **Короткие пробежки ЖТ (нЖТ) — детектируются примерно в половине случаев (D40).** Правило
  пробежек: на новых отложенных Холтер-базах (European ST-T, MIT-BIH Long-Term) sens 0.51 при
  0.12% ложных окон; на ЭКГ покоя Georgia/CPSC правило добавляет 0.1–0.2% вызовов ЖТ.
  Медленная ЖТ (100–130/мин, вся полоса) по-прежнему не отличается от синусовой тахикардии с
  БНПГ. Прежний LDA-путь ЖТ с ложными вызовами на ФП с БНПГ удалён (D41).
- **Ложная ФП на частой эктопии (D37):** парные ЖЭ и НЖЭ делают RR нерегулярным; правило
  «одиночная ЖЭ объясняет нерегулярность» (D25) их не покрывает. Расширение на любые аномальные
  удары (D39) без потери ФП на dev сняло лишь 10% ложных на INCART — не прошло; нужен анализ
  предсердной активности.

- **Длинный QT и АВ-I — улучшены глобальными границами волн (D30).** QT/PR теперь по
  12-канальному медианному комплексу, откалиброваны к GE 12SL (PTB-XL+). Фолд 10: QT vs 12SL
  MAE 38.7 → 12.1 мс; АВ-I PPV 0.10 → 0.28 (Georgia 0.17 → 0.40, CPSC 0.35 → 0.60); длинный QT
  фолд 10 0.64/0.64 → 0.73/0.73, Georgia sens 0.48 → 0.90 при spec 0.62 → 0.57 (один заранее
  заданный критерий не пройден — задокументировано). Промежуточные попытки D28/D29 — отрицательные.
  «Ложные» длинные QT против редкой метки — это сам порог нормы: GE 12SL считает QTc выше 450/460 у
  20.4% записей фолда 10, мы — у 22.8% (D44). Критическая тревога теперь с QTc ≥ 500 мс: фолд 10
  23% → 6% записей, новая выборка Georgia 45% → 16% при неизменной чувствительности находки (0.90).

- **Трепетание, названное синусом, частично ловится (D45):** без организованных P синусовая
  метка снимается, но отдельной находки «трепетание» по-прежнему нет. Оценка «трепетание 12/24»
  опиралась на метки Ningbo (D52); на исходном Chapman (D53) синусовую метку по-прежнему получают
  36% трепетаний (в основном 2:1 → «синусовая тахикардия»).
- **Трепетание предсердий и полная АВ-блокада — инертны** (трепетание — 4 этапа, последний D23: отличение от ФП среди вызовов ФП не прошло отложенную проверку — 11% истинной ФП переименовывалось; 16 из 29 отложенных трепетаний получают синусовую метку). Правила читают
  `atrial_rate_bpm`/`av_dissociation`, которые Layer 3 не вычисляет. Надёжный
  детектор трепетания требует подавления QRS + анализа организованности F-волн;
  простые методы (FFT, вычитание QRST-шаблона) дают ≥33% ложных — клинически
  вредно, не внедрено (v2).
- **ST-элевация: остаточное рассогласование тяжести.** Правило переведено на J+60
  + лид-специфичный порог V2–V3 (200µV) + смежность (D15j): 0.14/0.64 → 0.29/0.75.
  Оставшийся разрыв — от «рыхлой» метки `STE_`: часть её записей несёт элевацию
  100–200µV в V2–V3, которую гайдлайны справедливо не считают STEMI. Полный
  потолок — диагностическая полоса + сорт по полу (0.2/0.15 мВ V2–V3) — v2.
- **Ширина QRS — РЕШЕНО (D15o).** Раньше fiducial-offset мерил ненадёжно в обе
  стороны (недомер широких → RBBB, перемер нормы 40% ≥120 → ложные LBBB). Заменён
  энергетической оценкой (LUDB bias +4/MAE 14; NORM 1% ≥120, CRBBB 89%, CLBBB 100%):
  RBBB 0.42→0.82, LBBB spec 0.61→0.93. Остаток RBBB — амплитудно-малый терминальный
  R′; диагностическая полоса его не снимает (проверено, D15p) — нужен лучший делинеатор.
- **ST-депрессия — spec поднята J+60-замером** (D15k): 0.68/0.48 → 0.38/0.71.
  Остаточные «ложные» на **83% несут ГЛЖ/БНПГ** — это вторичный strain (D15q),
  морфологически идентичный ишемии, поэтому форменная типизация ST его не отличает
  (проверено, tol≥30µV не меняет ничего, tol 0 режет sens). Подавлять нельзя (37%
  истинного STD_ тоже с ГЛЖ — риск пропуска ишемии); Layer 5 уже контекстуализирует
  их как вторичные (`lvh_strain_chain`, `secondary_st_t`). Метрическая spec 0.71
  занижена артефактом одиночной ST-метки PTB-XL.
- **Фибрилляция желудочков (VF) — вне модальности (D15u).** VF отсутствует в
  12-канальной ЭКГ покоя (в VF её не снять); прототип флага дезорганизации на VFDB
  (2-канальный Holter) дал недостаточное разделение (ac<0.25 → 0.54/0.86). Надёжная
  детекция VF — задача монитора, многопризнаковый детектор для телеметрической
  модальности (v2), а не порог в интерпретаторе покоя. Не внедрено (§0).
- **Гейт организованности сигнала (§5, D15w).** При консистентности формы QRS <0.80
  (шум/артефакт) все R-пик-производные находки изымаются и заменяются
  `poor_quality_signal` — не репортим ложную брадикардию на шуме. Стоит −0.012 macro
  на PTB-XL (2–3 реально шумные записи/класс справедливо помечены), убирает опасный
  «уверенный мусор». Именно поэтому числа выше чуть ниже до-гейтовых (macro 0.72→0.71).
- **Специфичность на сабсетах занижена** — они обогащены патологией; на общей
  популяции ложных срабатываний меньше.
- **Полная АВ-блокада — инертна (D47).** Детектор диссоциированных P на остатке после отмены QRST
  не нашёл ни одной из 43 размеченных блокад при ≤ 0.5% ложных; метки неоднородны (у большинства
  нерегулярный желудочковый ритм; 28 записей Chapman — одна пачка подряд идущих номеров). Защита —
  «тяжёлая брадикардия» (< 40) и «пауза ≥ 3 с».

## Дальше

Состояние после D36–D84. Правиловые и измерительные рычаги на открытых данных в основном
исчерпаны; дальнейшее упирается в данные или в клинические решения:
1. **Реальные фото/сканы ЭКГ** — PM-ECG-ID: после D78–D79 читается 31% отложенных страниц (было 15%), сканы 12/14,
   пригодных 7 (было 2), медиана SNR принятых −2.0 → −0.1 дБ; все помечены и эскалируют.
   D80 (окно импульса от края сетки) и D81 (поиск строк по покрытию) — отрицательные: больше принятых или лучше на
   dev, но не больше пригодных на отложенных. Отложенная половина PM-ECG-ID использована пять раз — для новых правок
   нужна свежая отложенная выборка. Скачаны папки искажений PM-ECG-ID (перспектива, поворот; D82): на их dev-половине
   принято 8 из 75, пригодных 0 (лист на цветном фоне, тонированная бумага); отложенная половина не открывалась.
   Выпрямление листа по контуру (D83) снова дало больше принятых, но не больше пригодных — правила исчерпаны;
   нужна обучаемая сегментация кривой и сетки. Маленькая U-Net на синтетике (D84, CPU) на реальные фото не
   перенеслась — нужны размеченные реальные фото и обучение на GPU. Фото телефоном и экраны упираются в перспективу и изгиб
   бумаги — нужна геометрическая коррекция страницы или обучаемая модель (уровень Challenge 2024).
2. **Трепетание предсердий.** Сделано: метки Ningbo «трепетание» оказались ФП (D52); в метке ФП —
   оговорка «исключить трепетание» (D53: 22% трепетаний среди вызовов ФП, 1.3–2.1% истинной ФП на
   отложенных). Не закрыто: **36% трепетаний получают синусовую метку** (2:1 → «синусовая
   тахикардия»). Признаки II отведения их отделяют (AUC ≈ 0.89), но при естественной
   распространённости трепетание — 0.3% вызовов синуса: оговорка либо задевает 5% синуса с
   эктопией (D54, откачено), либо имеет PPV ≤ 0.16 (D55). Нужен признак другого класса (прямое
   выделение волн F после вычитания T по соседним комплексам) или контекст анамнеза.
   Уточнение (2026-10-04): вычитание усреднённого QRST не поможет именно при 2:1 — при фиксированном проведении
   волны F жёстко привязаны к QRS и уходят в шаблон вместе с ним; метод работает только при меняющемся RR.
   При доле трепетания 0.3% среди вызовов синуса нужен AUC ~0.99 — на 10-секундной записи такого признака нет. Длинные
   записи PhysioNet проверены: LTAFDB — трепетания нет, AFDB + MIT-BIH — ≤ 11 пациентов на
   2-канальном Холтере; для 12-канальных признаков недостаточно.
   Трепетание, названное СВТ (28 из 194): примечание «возможно 2:1» при 140–160/мин (D56) охватило
   61% таких трепетаний (41% примечаний — трепетание), но стояло на 1.07% записей свежей Georgia при
   пороге 1% — откачено; по решению по продукту (2026-10-01) остаётся откаченным.
3. **Полная АВ-блокада и медленная ЖТ** — детектор диссоциированных P не работает на доступных
   метках (D47); нужна согласованная разметка или длинные записи.
   Во всей Georgia (10 310 записей) меток полной блокады 8 (D77) — данных по-прежнему недостаточно.
4. **ЭКС без спайка** — многоканальный спайк по второй разности (D75) поднял найденные ЭКС на фолде 10 с 15 до
   18 из 28 без ложных; оставшиеся 10 — без различимого спайка (нужен сырой сигнал с высокой частотой дискретизации).
   Узкий QRS под стимулятором (D76): у 8 из 38 таких вызовов GE 12SL меряет QRS ≥ 130 мс, а спайк стоит за 6–12 мс
   до R — атриальную стимуляцию не отделить, подавление иерархией ЭКС оставлено.
5. **ГЛЖ и ГПЖ** — эхокардиографически подтверждённый эталон сверх вольтажа. ГПЖ (R/S в V1) в PTB-XL
   неотделима от морфологии правой ножки: метка RVH у 59 из 66 записей dev идёт с БПНПГ/неполной БПНПГ (D67).
6. **ФП против синуса с эктопией** — закрыто решением по продукту (2026-10-01): признак D42 остаётся
   доказательством и оговоркой в метке ФП (D51), вызов ФП не снимается — чувствительность к ФП
   важнее, чем −70% ложных ФП.
7. **Гиперкалиемия** — нет открытых меток; уровень тревоги D49 проверен только по измерению (с D65 находка
   «остроконечные T» всегда стоит при критерии высокого T, так что тревога не теряется из-за правила находки).

8. **Ось QRS** — по медианному комплексу (D69): ошибка против 12SL 7.7° → 5.6°, PPV отклонения влево на Georgia
   0.46 → 0.62; чувствительность к метке LAD Georgia 0.82 → 0.75 (граница −30°) — внедрено решением по продукту.

   на Georgia 3 из 25 истинных уходят в «неспецифическое расширение QRS» — внедрено решением по продукту.
