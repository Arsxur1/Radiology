# Перенос в ветку `claude/ekg-app-4epwud` (чат «ЭКГ приложение»)

Ветка-источник: `claude/vibrant-curie-ro1zsz` (этот файл лежит в ней). Обе ветки — один репозиторий
`Arsxur1/Radiology`, но разошлись с общего коммита `8d63456`: здесь 256 своих коммитов, там 126.
Ядро написано независимо (оцифровка, детские нормы, ФП, ось, LLM), поэтому `git merge` целиком даёт 24
конфликтных файла и ломает импорты. Переносить надо **по пунктам**, адаптируя к ядру целевой ветки.

## Правила переноса
1. Каждый пункт — отдельный коммит в целевой ветке; смотреть код источника:
   `git fetch origin claude/vibrant-curie-ro1zsz && git show <коммит>` и `git show origin/claude/vibrant-curie-ro1zsz:<файл>`.
2. Не копировать файлы ядра целиком (`rules.py`, `pipeline.py`, `measure.py`, нормы) — переносить логику.
3. Цифры валидации из `DECISIONS.md` источника относятся к его ядру. После переноса правила-порога —
   перемерить на тех же данных; если данных нет в контейнере — записать «не перемерено».
4. Номера решений в источнике D73–D122 пересекаются с целевыми (D68–D72 и дальше) — при переносе
   давать новый номер и ссылку «из vibrant-curie Dxx».
5. Наборы данных не коммитятся; при необходимости скачивать заново (ссылки — в `DECISIONS.md` источника).

Ветки разошлись после D22. Всё с D23 по D122 здесь — своё; взрослая часть — D23–D113. По кодам находок в
