## Что осознанно отложено (требует внешних данных/оборудования)
- **Оцифровка реальных фотографий**: бенчмарк пока на синтетических страницах с
  генератором порчи; калибровочный импульс и раскладки кроме 3×4 не детектируются.
- **DL-модели на сырых 12 отведениях** — обучаемый слой построен на признаках
  Слоя 3 (sklearn): ≈1.6k размеченных записей для CNN мало, torch из PyPI не ставится
  без CUDA-зависимостей. **Педиатрический fine-tuning** — нет размеченного детского
  набора (PTB-XL: 64 записи < 16 лет), сделана только возрастная страта оценки.
- **Реальные бенчмарки MAE интервалов** (LUDB) — доступны только диагностические метки.
- Дополнительные группы находок §7 (Бругада, ЖТ-морфология, электролитные паттерны
  сверх гипер-/гипо-K).
