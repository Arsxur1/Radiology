## Что осознанно отложено (требует внешних данных/оборудования)
- **Оцифровка реальных фотографий**: бенчмарк — синтетические страницы и страницы,
  отрисованные из реальных сигналов PTB-XL, с генератором порчи (скан, фото с
  перспективой); калибровочный импульс читается, раскладки кроме 3×4 не
  детектируются; ECG-Image-Database из среды недоступна.
- **DL-модели на сырых 12 отведениях** — обучаемый слой построен на признаках
  Слоя 3 (sklearn, признаки v2 со средним комплексом по отведениям): ≈3k размеченных
  записей для CNN мало, torch из PyPI не ставится без CUDA-зависимостей.
  **Педиатрический fine-tuning** — есть когорта 1591 ребёнка с ритмическими
  метками, но нет размеченных детских интервалов; сделаны нормы по полосам и
  оценка по полосам.
- Дополнительные группы находок §7 (Бругада, ЖТ-морфология, электролитные паттерны
  сверх гипер-/гипо-K).
