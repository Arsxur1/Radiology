**Недоношенные** (picsdb, 10 детей, одно отведение монитора, окна по 10 с, D101; отложенные — дети 6–10):
- ЧСС: медиана ошибки 0.6/мин против проверенных R-зубцов.
- Эпизод брадикардии (мгновенная ЧСС < 90) назван в 201/203 окнах (было 28); ложных 2.9%; автономных отчётов
  среди эпизодов 0 (было 5).
- Ложная ФП: 199 → 117 окон.
- Ограничение: QT завышен (медиана 298 мс при ЧСС 147); тревога «длинный QT» в 38 из 300 случайных окон. Эталона QT

**Вход DICOM-ECG** (D93): на образце 12-канальной ЭКГ ЧСС, QRS, PR и ось совпадают с измерениями прибора

## 3. Интервалы

LUDB (200 записей, эталон — экспертная разметка, сырые значения без калибровки): PR — смещение −16, MAE 19.9 мс;
QRS — +2 / 11.7 мс; QT — −20 / 29.5 мс. Против экспертного глобального эталона LUDB: QT 24.5, PR 13.4 мс.
Против GE 12SL на отложенном фолде 10 (с калибровкой D30): QT 12.1, PR 10.8 мс, QRS ~7 мс.
Против кардиолога на QT Database (105 двухканальных записей, окна 10 с, D102): медиана ошибки QT +2…+7 мс, MAE 35–43 мс.
15–17% окон ошибаются больше чем на 60 мс, когда конец T не возвращается к изолинии до границы поиска. Правка этого
(D102) прошла три из четырёх критериев, но потеряла 2 размеченных удлинённых QT на Georgia и откатана.
На тех же окнах (D103): PR — медиана −4 мс, MAE 18.5 мс; QRS — медиана −4 мс, MAE 19 мс. Широкий QRS (≥ 120 по
кардиологу) на двух отведениях холтера недомеряется: ≥ 120 у нас в 70/120 окнах.

## 4. Причинно-следственный слой

- **Подставленная перестановка электродов (D92).** 300 записей PTB-XL фолд 9 (dev), программно переставлены
  LA/RA (I → −I, II ↔ III, aVR ↔ aVL):
  - гипотеза «реверс LA/RA» выставлена у **232 из 300 (77%)**;
  - на тех же записях без перестановки — у 7 из 300 (2.3%);
  - режим B не выдал автономного отчёта ни по одной из 300 переставленных ЭКГ.
- Физиологично/патологично: каждое правило графа помечено `physiologic`; неправдоподобные созвездия (находка без
  объясняющего механизма) поднимают `implausible_flags`, и режим B эскалирует. Тесты: `tests/test_layers.py`.
- **Не измерено:** согласие цепочек с экспертом — нет экспертной разметки причинных цепочек.

## 5. Оцифровка

- Чистые рендеры ecg-image-kit, отложенные: медиана SNR отведения 12–16 дБ, ЧСС ±5 уд/мин в 96–100%.
- Цветная сетка: ~10–11 дБ.
- Реальные фото и сканы PM-ECG-ID, отложенная половина: принято 30 из 98 страниц, пригодных (≥ 5 дБ) 7.
- Уверенность снижается корректно: каждая деградированная страница помечена, и режим B эскалирует. Неверного
  масштаба или ЧСС без пометки — 0.

## 6. Режим B (автономный)

Свежая выборка Georgia d88_ga (2 000 записей, для правил не использовалась), код после D92:

| Показатель | Без потолков (до D85) | Сейчас |
|---|---|---|
| Доля автономных отчётов | 22.0% | **15.2%** |
| ECE уверенности находок (n = 4 977) | 0.436 | **0.222** |
| Средняя уверенность / совпадение с меткой | 0.79 / 0.36 | 0.58 / 0.36 |

Эскалация при метках, требующих врача:

| Метка | Эскалировано |
|---|---|
| БЛНПГ | 51/51 |
| ЭКС | 27/27 |
| Трепетание | 42/42 |
| ФП | 2/2 |
| Удлинённый QT | 269/271 |
| Элевация ST | **25/27** (до гейта J-точки D92 — 23/27) |

- Две оставшиеся ЭКГ с меткой элевации ST не проходят ни правило J+60, ни J-критерий UDMI (подъём < 1 мм).
- Автономные отчёты (305) содержат только синусовые метки и ГЛЖ; совпадение находок с меткой — 76%. Часть
  расхождений — неполнота меток Georgia: синусовый ритм размечен не у всех синусовых ЭКГ.
- ECE остаётся 0.22: метки Georgia неполны (совпадение 0.36 при любой уверенности), и потолки не опускаются ниже 0.30.

**CODE-15% (D107):** из 435 автономных отчётов 165 (38%) — на ЭКГ, которые врач в заключении нормой не назвал. Из
шести размеченных патологий ни одна не пропущена; остальные отклонения набор не называет. По умолчанию — режим A.

## 7. Покрытие тестами

`pytest --cov=cardiolens` — порог **85%** (`[tool.coverage.report] fail_under`), проверяется в CI. Сейчас 93% без
CLI-скриптов офлайн-данных (demo, train_beats, validate). Парсеры файлов — 95% (EDF, CSV, WFDB, DICOM, диспетчер),
загрузчик PTB-XL — 100%. Клиент Claude — 95%: проверяется против подменного SDK без сети — форма запроса, отсутствие
демографии в запросе, отбрасывание незаземлённого утверждения, отказ модели → локальный нарратив.
